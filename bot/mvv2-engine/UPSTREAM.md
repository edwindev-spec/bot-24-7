# Procedencia

Este motor se incorporó desde el ZIP `deobfuscator.zip` proporcionado por el usuario. Su README describe una implementación nueva para el perfil de MoonVeil 2.1.0 table-dispatch, guiada por [`edwindev-spec/MoonVeil`](https://github.com/edwindev-spec/MoonVeil), commit `a948c4849a692f0af40d554708cac28b610c5115` (deobfuscator 1.4.5). El código de esta herramienta se distribuye bajo MIT; véase `LICENSE.txt`.

El archivo de muestra y las pruebas incluidas en el ZIP se usaron localmente para validar el paquete, pero no se copian al repositorio público del bot. Luau es un componente independiente y conserva la licencia oficial MIT en `../mv-engine/LUAU_LICENSE.txt`; el Dockerfile compila la versión oficial 0.722 fijada por commit.
